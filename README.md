1. What is the difference between var, let, and const?
var, let, and const in JavaScript differ mainly in scope and reassignability. var is function-scoped (or global), hoisted, and re-declarable. let and const are block-scoped (scoped to {}), with let allowing reassignment and const prohibiting it. const requires initialization, while let and var do not.  

2. What is the spread operator (...)? 
The spread operator (...) in JavaScript is a syntax that expands iterables (like arrays, strings, or objects) into individual elements or properties. It is commonly used to create shallow copies, merge arrays/objects, or pass arguments to functions without mutating original data. 

3. What is the difference between map(), filter(), and forEach()? 
The core difference lies in their purpose and return value: map() transforms each element into a new array, filter() selects elements into a new array based on a condition, and forEach() performs an action on each element without returning a new array. 

4. What is an arrow function? 
Arrow functions, introduced in ES6 provide a more concise and readable syntax for writing function expressions in JavaScript, typically characterized by the => ("fat arrow") symbol. They are designed to address verbosity in traditional function syntax and offer specific behavioral improvements, particularly regarding lexical this binding. 

5.  What are template literals? 
Template literals, introduced in ES6, are a powerful way to create strings in JavaScript using backticks (`) instead of quotes. They allow for easy string interpolation using ${expression} syntax, multi-line strings without needing newline characters (\n), and cleaner, more readable code compared to traditional string concatenation.
